## 2. Типичное задание

> В текстовом файле содержится описание ациклического ориентированного взвешенного графа. В каждой строке файла записаны два натуральных числа (L, M) и одно положительное вещественное число (W). L и M: номера вершин графа; W: вес ребра, ведущего из вершины L в вершину M.
>
> Найдите и запишите в ответе целую часть длины кратчайшего пути из вершины с номером 1 в вершину с номером 100.

Пример файла:

```
100  12  1.0
6    7   7.0
6    1   1.0
1    7   5.5
7    100 2.0
4    100 8.0
1    100 12.0
1    4   2.5
```

Пути из 1 в 100: `1→100` (12), `1→4→100` (10,5), `1→7→100` (7,5). Кратчайший равен 7,5, ответ **7**.

---

## 3. Ключевые понятия

- **Ориентированный граф**: у каждого ребра есть направление, поэтому ребро `L→M` нельзя пройти обратно.
- **Ациклический**: нельзя выйти из вершины и вернуться в неё. Поэтому у любой вершины конечное число путей, и задачу можно решать рекурсией с запоминанием, как задание 13 или 16.
- **Вес ребра**: длина дороги. **Длина пути** равна сумме весов его рёбер.

---

## 4. Метод: «ответ для вершины = через ответы для её предков»

Это тот же приём, что в задании 13 (подсчёт программ): чтобы попасть в вершину `v`, нужно прийти в неё из какой-то вершины `u` по ребру `u→v`.

| Что ищем | Формула для вершины `v` | Старт |
|:---|:---|:---|
| Кратчайший путь | `dist(v) = min(dist(u) + w(u, v))` по всем рёбрам `u→v` | `dist(1) = 0` |
| Самый длинный путь | `dist(v) = max(dist(u) + w(u, v))` | `dist(1) = 0` |
| Количество путей | `paths(v) = сумма paths(u)` по всем рёбрам `u→v` | `paths(1) = 1` |

Почему это работает: граф ациклический, поэтому рекурсия от `v` к предкам всегда закончится на вершине без входящих рёбер.

## 5. Считывание графа из файла

Числа разделены **произвольным** количеством пробелов и табуляций, поэтому используем `split()` без аргументов. Номера вершин идут не подряд, поэтому храним граф в словаре, а не в списке.

```python
into = {}                      # into[v] = [(u, w), ...]: рёбра, входящие в v
for line in open('23.txt'):
    if not line.split():       # пропускаем пустые строки
        continue
    l, m, w = line.split()
    into.setdefault(int(m), []).append((int(l), float(w)))
```

## 6. Шаблон: кратчайший путь

```python
from functools import lru_cache

@lru_cache(None)
def dist(v):
    if v == 1:
        return 0
    return min((dist(u) + w for u, w in into.get(v, [])), default=float('inf'))

print(int(dist(100)))          # «целая часть»: int(), а не round()
```

`default=float('inf')` нужен для вершин, в которые не входит ни одно ребро: из вершины 1 до них не добраться.

## 7. Шаблон: количество путей

```python
from functools import lru_cache

@lru_cache(None)
def paths(v):
    if v == 1:
        return 1
    return sum(paths(u) for u, w in into.get(v, []))

print(paths(100))
```

Путей бывает миллиарды, поэтому перебирать их по одному (DFS по всем путям) нельзя: программа не закончится. Рекурсия с `lru_cache` считает каждую вершину один раз.

## 8. Типичные ошибки

| Ошибка | Как избежать |
|:---|:---|
| `line.split(' ')` ломается на табуляциях и двойных пробелах | `line.split()` без аргументов |
| Граф в списке `[0] * 101`, а номера вершин до 1000 и не подряд | Словарь `dict` |
| Рёбра считаны как неориентированные | Ребро только `L→M` |
| `round()` вместо целой части | `int()` |
| Без `lru_cache` время работы экспоненциальное | Всегда кэшировать рекурсию |
